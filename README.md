# Universo Lay

Site/loja do **Universo Lay** — "Todas as suas marcas em um só lugar." (Lay.Store · Ousada Delicada · Falou Bordei)

- `npm run dev` — desenvolvimento
- `npm test` — testes unitários
- `npm run build` — build estático (GitHub Pages)

Design: `docs/superpowers/specs/` · Plano: `docs/superpowers/plans/`

## Deploy (GitHub Pages + domínio próprio)

O site publica sozinho a cada alteração na `main` (e a cada hora, pra atualizar as páginas de compartilhamento).
Domínio: **https://universolay.com.br** (DNS no Registro.br; *Settings → Pages → Custom domain*; *Enforce HTTPS* ligado).

Guia completo de uso e edição: [`docs/COMO-USAR-E-EDITAR.md`](docs/COMO-USAR-E-EDITAR.md).
