# Guia visual — Universo Lay

**Conceito:** boutique multimarcas editorial. Papel quente, serifa leve, filetes finos, foto fundida ao fundo. Contenção em vez de efeito.

## Cores
| Uso | Valor |
|---|---|
| Papel (fundo) | `#F7F5F2` · areia `#ECE5DF` · branco `#FFFFFF` |
| Tinta (texto) | `#28272B` |
| Lilás de marca | `#A38A9E` · texto pequeno `#76607A` |
| Vazio (rodapé/hero das marcas) | `#0B0A0D` |
| Lay.store | `#9FB8FF → #A38A9E` |
| Ousada Delicada | `#F2A7C8 → #A38A9E` |
| Falou Bordei | `#D9B98A → #A38A9E` |

## Tipografia
- **Cormorant Garamond** (títulos): 400–500; itálico para a ênfase da frase principal. Nomes de produto em 500.
- **Manrope** (interface): 400–700. Rótulos 12,5 px em caixa-alta; corpo 16–17 px.

## Componentes
Cantos retos; botões retos com preenchimento que sobe ao passar o mouse; painéis brancos com filete colorido no hover; fotos com `mix-blend-mode: multiply` sobre areia; toasts escuros no topo; menu em pílula de vidro (desktop).

## Fotos (o que mais melhora o resultado)
Fundo neutro e liso, luz natural difusa, proporção 4:5, peça centralizada. O site ajusta o resto.
